# 2026-07-30 工作日志

## 游戏设计诊断与重设计

### 诊断
- 全面审计了《博三之前》项目（GDD、ROADMAP、核心代码、150+规格说明、试玩数据）
- 识别出"不好玩"的5个根本原因：
  1. 核心循环是"填进度条"而非"做决策"
  2. 卡牌设计是"+1按钮"而非"效果引擎"
  3. 没有动态对抗（无危机系统）
  4. 搜打撤心理张力没有落地
  5. 文档过剩，玩法验证不足

### 关键设计决策
- 保留项目核心理念（研究生不确定性决策 + 方法构筑 + 搜打撤）
- 核心变化：引入"危机系统"作为动态对手，让每回合都在压力下做决策
- 课题不再用抽象数值表示，改为可视化的"进度卡拼图"
- 所有数值标记为 [PLACEHOLDER]，需真人试玩后校准
