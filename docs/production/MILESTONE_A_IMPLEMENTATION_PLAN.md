# 里程碑 A：主循环复位实施计划

状态：进行中  
设计依据：`docs/game_design/VISION_RESTORE_GDD_V3.md`

## 已确认的复用边界

- 保留：`BattleState` 的回合、牌堆、资源与确定性随机逻辑。
- 保留：现有卡牌 `Resource` 数据层与 `GameDataCatalog`。
- 保留：校园路线进入战斗、战斗结果回写与场景切换能力。
- 保留：B001 数据定义，后续按纵切片数值裁剪。
- 改造：`RouteState` 从完整硕博路线收窄为“研一开题”短路线。
- 改造：`MetaProgressionState` 从抽象资源累计改为单件研究遗产装备。
- 改造：结算页从统计汇总改为“原因 → 遗产 → 下一局用途”。
- 隔离：`lab_engine` 继续作为内部沙盒存在，但不参与正式主流程。

## 场景职责

- `campus_overworld_scene.tscn`：当前临时正式入口，承接路线选择和战斗转场。
- `battle_test_scene.tscn`：复用中的卡牌战斗场景；后续去除测试命名和超范围内容。
- 新的愿景恢复入口：只负责研究倾向选择、存档遗产展示和开始短路线。
- 流程控制器：持有单局跨场景状态；UI 不直接成为状态真源。

## 本里程碑余项

1. 建立愿景恢复入口与运行状态对象。
2. 将校园入口收窄为 3–4 个连接节点。
3. 加入固定 Seed 冒烟路径。
4. 验证从启动到第一场卡牌战斗完整可达。

## 禁止项

- 不把实验室生产链资源复制进卡牌战斗。
- 不在入口 UI 中堆放战斗、路线和存档业务逻辑。
- 不删除历史原型；仅从正式入口隔离。
- 不在完成短路线前扩充博士路线、卡池或永久属性。
