# 阶段 8：自动试玩与策略审计基线

日期：2026-07-19  
冻结版本：0.1.0  
定位：真人封闭试玩暂不阻塞开发；自动审计用于发现固定解和伪选择，但不冒充真人乐趣结论。

## 已通过证据

- 课题响应审计：60 个 Seed 中，响应课题使候选选择改变 76.67%；响应策略与基线各有优势样本，课题奖励可达且不形成绝对支配。
- 中期取舍审计：288 个控制局面中，41.32% 至少存在两条近似最优路线；维护、追课题、扩产均达到可信场景门槛。
- 策略多样性审计：120 个 Seed × 3 种可解释启发式策略，共 360 局。
  - 单一首选工位最高集中度：32.50%，低于 70% 门槛。
  - 不同前四日序列：150 种；最常见序列占 5.56%，低于 50% 门槛。
  - 可信代理在固定 Seed `240731` 复现胜利，论文进度 130。
- 七项固定门禁覆盖编译、单元、黄金路线、场景、布局、稳定性和策略多样性。

## 解释边界

简单启发式策略的完整胜率很低（流水线 0%、课题 0%、兑现 1.67%）。它们没有完整的多日规划能力，因此只用于观测候选与开局分布，不用于裁决整体难度或路线强弱。任何数值调整必须依赖能先通过黄金 Seed 可信度门槛的搜索代理，或真实玩家数据。

当前结论是“没有检测到统一首选或通用前四日脚本”，不是“已经证明游戏足够有趣”。真人首次理解、情绪曲线和主动重玩率仍保留在阶段 8 待验证项中。

## 下一开发动作

1. 冻结卡池与核心数值，不因低可信自动策略失败而调参。
2. 将策略多样性审计纳入每次发行门禁，防止后续美术/UI修改意外改变玩法状态。
3. 下一制作阶段优先推进正式美术语言与信息层级；不添加地图、剧情、商店或局外成长。
4. 一旦获得真人观察记录，按 P0/P1 立即处理，P2/P3 批次复盘。
