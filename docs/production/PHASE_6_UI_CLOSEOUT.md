# 阶段 6 UI 与表现收敛验收

验收日期：2026-07-19  
裁决：通过

## 已通过范围

- 根级 Theme 统一普通按钮、焦点、禁用态与基础文字颜色。
- 1280×720、1920×1080、1280×800 三档完整场景布局门禁。
- 帮助、设置、结算采用全屏阻断模态层，共享遮罩与面板视觉语言。
- Esc 返回、焦点自环、打开前焦点恢复与首次教程候选焦点回退。
- 长结算摘要使用可由鼠标、键盘和手柄访问的滚动区域，操作按钮固定在滚动区外。
- 隐藏模态和累计课题退出焦点图，避免自动导航进入不可见控件。
- 候选卡装饰徽章不拦截父按钮点击。
- UI 不再使用 `Control.scale` Tween，避免 Container 几何与命中区域不一致。

## 验验证据

- compile、unit、golden、scene-smoke、layout-smoke 全部通过。
- layout-smoke 对三种尺寸检查关键节点可见、边界、横纵区域关系及长结算滚动。
- 实机截图：主工作台、帮助模态、设置模态、长失败结算均无首发阻断。
- 独立 UI 审查最终裁决：通过；首发阻断为零。

## 冻结与延期

以下项目为非阻塞表现润色，按用户优先级延期，不进入阶段 6 返工：

- 更复杂的粒子、镜头抖动与卡牌动效。
- 正式音频资产、分轨混音与音效强度精调。
- 移动竖屏、超宽屏、完整手柄提示图标。
- 纯装饰插画与世界观背景细节。

后续阶段若新增 UI，不得破坏本阶段的五道门禁与焦点/输入规则。
