# 阶段 0—3 范围冻结

生效日期：2026-07-16  
适用版本：《博三之前：实验室引擎》垂直切片

## 当前产品承诺

在 8 天内通过安装、升级、跳过和超频调整实验室生产链，使论文进度达到 100。核心乐趣来自生产链组合、资源转化、连锁触发与技术债风险之间的取舍。

## 阶段 0—3 允许工作

- 修复阻塞、规则歧义、确定性和边界条件问题。
- 为模拟层、候选生成、停机、债务、触发上限、升级与跳过补自动测试。
- 拆分 `lab_workbench.gd` 的界面职责，保持现有玩法和结果不变。
- 将卡牌、构筑标签、数值和音效映射迁移到可校验的数据资源。
- 改善教程、可读性、输入锁、重开安全和必要的即时反馈。
- 更新 GDD、测试证据、性能记录与开发日程。

## 冻结事项

在阶段 4“三种构筑差异”通过前，不开发：

- 地图、Boss、剧情、角色对话、商店或探索模式。
- 局外成长、永久货币、成就、排行榜或每日挑战。
- 第四种构筑、大型卡池、大量随机事件或稀有度系统。
- 正式美术资产、复杂粒子、过场动画或完整配乐。
- 手柄、移动端、多语言和非 Windows 首发平台。
- 与当前实验室生产链无关的旧原型扩展。

## 变更规则

新想法只进入待办，不插入当前阶段。只有当它能解决已记录的玩家问题，并且不推迟当前阶段验收门槛时，才可由主开发 Agent 写入日程。任何范围扩张都必须同时写明要删除或延期的等量工作。

## 硬性止损

- 连续两轮未通过阶段门槛：停止加内容，回到最近基线。
- 新功能无法用一句话说明新增了什么决策：不做。
- 新卡只增加产量、不改变取舍：合并为升级或删除。
- 玩家同时“不懂”和“不好玩”：先解决“不懂”。
