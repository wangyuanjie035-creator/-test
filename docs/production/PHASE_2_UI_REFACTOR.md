## 当前问题

`scripts/lab_engine/ui/lab_workbench.gd` 当前约 503 行，同时负责界面构建、HUD 刷新、候选交互、教程、事件播放、资源 Token、音效调度和结算面板，重开与后续表现优化容易互相影响。

## 目标边界

| 组件 | 单一职责 | 通信方式 |
|---|---|---|
| `LabHudView` | 标题、天数、进度、资源与帮助入口 | 父级调用 `refresh()`；帮助按钮发信号 |
| `LabCandidatePanel` | 候选卡和选择状态 | 用户选择向上发信号；父级调用 `show_candidates()` |
| `LabSidebarView` | 状态、日志、跳过和开始一天 | 用户操作向上发信号；父级调用刷新与输入锁方法 |
| `LabHelpOverlay` | 教程内容的显示与关闭 | 自己处理关闭；父级调用 `show_help()` |
| `LabDayPlayback` | 顺序播放事件、工位脉冲、Token 与反馈/音效协调 | 父级传入结果并等待完成 |
| `LabResultOverlay` | 成功/失败摘要、差值、断点诊断和重开选择 | 重试/换 Seed 向上发信号 |
| `LabWorkbenchView` | 创建运行控制器、协调日流程和组件 | 只保留流程编排与状态所有权 |

不引入全局 EventBus。组件是工作台的直接子级，遵循“子级信号向上、父级方法向下”。
