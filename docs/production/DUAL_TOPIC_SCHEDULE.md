# 双课题决策原型开发日程

设计基线：`docs/game_design/DUAL_TOPIC_GDD_V4.md`

## M1 状态模型与确定性（2 个开发日）

状态：**已完成（2026-07-27）**。Godot 实机验证通过：双课题独立状态、Seed 确定性、风险状态机、投稿规则与不可逆承诺。

- 课题定义、风险定义和运行时状态分离。
- 两个课题独立持有证据、完成度、风险和项目档案。
- Seed 预生成风险与试验结果序列。
- 单元测试覆盖风险状态转换、取值边界与确定性。

通过：相同 Seed 生成相同课题风险；运行时不修改共享 Resource。

## M2 六周行动循环（2 个开发日）

状态：**底层循环已完成（2026-07-27）**。已实现并由运行中的 Godot 编辑器验证：四行动点、精力归零提前结束、压力阈值、调查/试验/整理/写作/恢复、加码每周代价与首次行动奖励、六周归档。下一步由 M3 方法牌替换临时动作入口。

- 周数、行动点、精力、压力。
- 方法牌指定 A/B/自身。
- 周末结算和压力阈值。
- 精力归零结束本周但不立即判负。

通过：可以不依赖 UI 跑完六周模拟。

## M3 最小方法牌与构筑（3 个开发日）

状态：**已完成（2026-07-27）**。15 张起始方法牌、五类标签、确定性抽弃牌循环、A/B/自身目标校验已完成。第 2、4 周从现有方法库生成确定性三选一，可加入副本提高稳定性或替换旧牌改变构成；整局最多两次。调查路线可优先扩大风险信息面，试验路线可把已揭示不确定性转化为证据。Godot 回归与 M3 专项测试通过。

- 15 张基础方法牌。
- 调查、试验、组织、协作、生存五类。
- 第 2、4 周三选一加入或替换。
- 验证牌改变信息、风险或结构，而不是只换资源。

通过：至少两种构筑在相同课题上产生不同风险处理路线。

## M4 中期判断（2 个开发日）

状态：**已完成（2026-07-27）**。第 3 周以一次原子决策同时处理两项课题；非法组合不会留下部分状态，且禁止同时止损。维持、加码、转向、拆分、止损均已实现：转向替换已揭示风险并回到未知，拆分降低潜力并移除风险槽，加码接入每周成本与首次行动奖励，止损生成保留风险认知和已用方法的本局资产。Godot M1–M4 全部回归通过。

- 维持、加码、转向、拆分、止损。
- 每个课题独立选择，至少保留一个。
- 决策后果进入项目档案和后续规则。

通过：五种操作均可机器验证，不生成第三课题。

## M5 投稿与遗产闭环（3 个开发日）

状态：**已完成（2026-07-27）**。公开开题要求由 Seed 确定并从开局可见；第 6 周可投稿一个保留课题或主动撤出，结算只读取已形成状态，不再掷隐藏骰。普通、优秀、失败、主动撤出均有因果结果；成功生成成熟方法，撤出生成风险认知，失败按理论、证据、风险或表达断点生成补救方法。最终选择不可逆且每局只有一项最终遗产。Godot M1–M5 全回归通过。

- 普通、优秀、失败、主动撤出。
- 因果诊断。
- 成熟方法、风险认知、四类补救方法。
- 下一局两分钟内兑现。

通过：三类结算的奖励强度和用途明确不同。

## M6 可玩 UI 与美术纵切片（3 个开发日）

状态：**机器门槛已通过，等待真人试玩（2026-07-28）**。独立双课题纵切片场景已经可运行：公开要求、六周时间线、A/B 目标选择、风险档案、方法手牌、加入/替换构筑、第 3 周双课题承诺、第 6 周投稿/撤出与因果结算均已接入真实模型。统一深色实验室主题、稳妥课题与高风险课题的形态差异、五类方法牌语义色已经落地；结算页会汇总 A/B 投入、方法类型和构筑路线，并根据本局行为生成下一局挑战。研究档案已使用带版本号的独立存档：成熟方法会在下一局加入牌组，风险认知会自动揭示风险，失败补救会提供对应的开局修正，满足“两分钟内兑现”。1280×720 首屏、中期和结算均由运行中的 Godot 实例检查。自动 UI 烟雾测试已覆盖从第 1 周到结局的完整路径，档案存取及下一局兑现专项测试、M3–M5 回归同时通过。剩余仅为 10–15 分钟真人完整试玩；真人门槛在获得真实样本前保持 `INCONCLUSIVE`。

2026-07-28 试玩修正：针对“固定调查→实验→组织/写作”与无调查牌死手，行动前置条件改为软前置。实验、组织、写作和满精力恢复均获得低收益或带压力的备用结果；调查仍保持最高安全性。投稿面板新增逐课题条件预览，明确区分“已验证”与“已受控”。软前置专项测试及全套回归通过。

- 双课题档案桌面。
- 风险从未知到验证的可视变化。
- 六周时间线和中期承诺。
- 投稿/撤出结算。

通过：10–15 分钟完整可玩，真人观察按 GDD 阈值记录。

## 护栏

- 旧统一论文进度战斗和实验室生产链暂停扩展。
- 每个里程碑必须增加可玩决策，不以文档或审计数量计进度。
- M5 前不扩卡池；M6 前不加入导师、校园、经费、声望或多学期。

## M8：阶段 2——立项未知与课题组合（进行中）

- 目标：让立项、调查、加码和撤回形成“投入—获取信息—重新判断—兑现/撤出”的信息循环。
- 立项信息由确切风险数量和确切收益，调整为风险轮廓、基础价值、潜在区间与未知上限。
- 调查揭示必须改变成本、推荐方法、收益上限、撤回资产或课题关系之一。
- 用稳健复现、冒险探索、资产回收三套临时构筑倾向验证单课题、协同双课题与冲突双课题。
- 阶段末设独立校准门：固定 Seed 对照测试“风险轮廓模糊程度”；不能因文案已修改而自动判定通过。
- 终局设计同步冻结为“毕业轴 × 去向轴”，本阶段只保留所需统计钩子，不提前实现完整就业系统。
- 护栏：不扩充大型卡池，不加入第二套经济，不以新增审计文档代替可玩决策。
## M7：一学年纵切片（已完成）

- 目标：把六周双课题原型变成一个研究周期，并串联三个周期。
- 预计：3–5 个开发日。
- Day 1：**已完成**。学年状态模型、三个投稿窗口资源、机械测试。
- Day 2：**已完成（2026-07-28）**。研究档案桌显示当前投稿窗口、门槛、起始压力和年度成果；六周结算后依次进入春季工作坊、暑期学术会议、秋季期刊窗口，第三周期结束后展示学年结局。
- Day 3：**已完成（2026-07-29）**。现有双课题投稿结果写入学年档案；成功、失败与撤回分别形成下一周期遗产，止损资产继续兑现；周期末压力按结果结转，并叠加下一投稿窗口的入场压力。三个窗口的证据/完成度门槛已进入真实投稿判定与条件预览，不再只是展示文本。
- Day 4：**已完成（2026-07-29）**。学年结局会逐项列出三个投稿窗口的结果、采用路线、声望收益与压力变化，并依据全年主要选择生成“专注型、协同型、高压并行型”研究风格总结。首轮路线平衡建立“单课题额外减压、协同双课题成功声望 +1、冲突双课题成功声望 +2”的风险回报梯度；冲突路线仍承担原有每周组合压力。
- Day 5：**机器闭环已完成（2026-07-29），真人时长门槛待样本确认**。三个周期可连续归档并生成年度历史、研究风格与结局；修复三路线平票被误判为专注型的问题，新增“多元探索型”总结；学年结算可携带已获得的局外研究遗产直接开始下一学年。完整流程、三条路线收益和窗口门槛已进行确定性模拟；30–45 分钟真人时长与主观乐趣仍标记为 `INCONCLUSIVE`，不由 Agent 冒充真人结论。
- 护栏：不加入导师、校园探索、社交、经费和课程系统。
