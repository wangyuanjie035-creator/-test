《博三之前：实验室引擎》封闭试玩版 0.1.0

目标：在 8 天内把论文进度推进到 100。

启动方式：
1. 解压整个压缩包，不要只单独拖出 EXE。
2. 双击 LabEngine.exe。
3. 第一次启动如出现 Windows 安全提示，请核对压缩包 SHA-256 后再决定是否运行。

完整性校验：分发时应同时收到同名的 .zip.sha256 文件。在压缩包所在目录打开 PowerShell，运行：
Get-FileHash .\LabEngine-Playtest-0.1.0-Windows-x86_64.zip -Algorithm SHA256
结果应与 .zip.sha256 文件第一段字符完全一致。

建议环境：Windows 10/11，1280×720 或更高分辨率，键盘和鼠标。

试玩要求：
- 第一局请独立游玩，不查攻略，也不接受旁人解释。
- 可以自行打开右上角“玩法说明”。
- 成功或失败后，请保留结算画面并填写反馈。
- 如果愿意，可立即再玩一局；第二局不要求使用相同策略。

多人共用同一 Windows 账户时：每位新玩家开始前，由观察员关闭游戏并删除
%APPDATA%\Godot\app_userdata\+test\lab_engine
以免继承前一位玩家的教学和设置状态。不要删除整个 +test 目录。

若发生崩溃或无法继续，请保留结算/故障截图，并提交：
%APPDATA%\Godot\app_userdata\+test\logs
中的最新日志，同时注明玩家编号、发生日期与操作步骤。

这是尚未公开发布的测试版本。请不要外传安装包或截图。
