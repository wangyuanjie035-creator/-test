# 阶段 8：封闭试玩入口清单

## 冻结范围

- 试玩批次内不修改卡牌数值、候选生成、生产链、停机、维护、超频或胜负目标。
- 只允许修复 P0/P1；P2/P3 统一进入批次复盘，不在两名玩家之间临时调整。
- 每个试玩者使用同一个版本与校验值，避免样本不可比较。
- 多人共用 Windows 账户时，每位新玩家开始前仅清除 `%APPDATA%\Godot\app_userdata\+test\lab_engine`，并在观察表确认；不得删除整个 `+test` 目录。

## 最小样本

- 第一轮 3 名首次玩家，用于发现理解与阻塞问题。
- 无 P0/P1 后扩展到 5–10 名。
- 至少 2 名玩家自愿完成第二局，用于观察策略变化与立即重玩动机。

首轮 3 人采用人数口径：核心理解要求 3/3；每名失败玩家逐个记录归因，不计算失败者百分比；立即重玩只按实际点击并开始第二局计算，要求至少 2/3。扩展到 5–10 人后，百分比一律向上取整到人数；若没有失败样本，则“失败归因”记为暂不可评估，不视为通过。

## 放行指标

- P0/P1 为 0。
- 至少 80% 玩家能在第一局后解释生产链、超频和技术债。
- 至少 75% 失败玩家能说出下一局要改变什么。
- 至少 60% 玩家愿意立即再开一局。
- 第一候选或固定开局的集中度需要被记录；任何单一首选超过 70% 时进入玩法复盘。
