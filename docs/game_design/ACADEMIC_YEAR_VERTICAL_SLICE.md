# 一学年纵切片

## 目标

将已经验证有趣的“六周双课题决策”定义为一个研究周期，而不是完整研究生生涯。三个周期组成一学年，目标游玩时长为 30–45 分钟。

## 核心节奏

1. 在研究档案桌选择本周期投稿窗口与继承成果。
2. 进入六周双课题循环，调查、试验、组织、写作，并处理风险。
3. 投稿、撤回或失败，得到明确结果与一项可兑现遗产。
4. 压力、论文、声望与研究档案带入下一周期。
5. 三个周期后依据成果与代价形成学年结局。

## 三个投稿窗口

| 周期 | 窗口 | 作用 |
| --- | --- | --- |
| 1 | 春季工作坊 | 低门槛，建立第一份公开成果 |
| 2 | 暑期学术会议 | 中等要求，检验上一周期积累 |
| 3 | 秋季期刊窗口 | 高要求、高回报，形成终局抉择 |

## 跨周期反馈

- 通过：获得论文与声望，压力小幅下降。
- 优秀：获得更高声望，压力明显下降。
- 撤回：没有论文，但保存风险认知并显著缓解压力。
- 失败：没有论文，得到补救方法，但压力上升。
- 所有结果都会留下研究档案，失败不等于白玩。

## 学年结局

- 尚未发表，但留下了研究档案。
- 站稳脚跟的一学年。
- 形成了自己的研究方向。
- 成果到手，代价仍在累积。

## 范围护栏

本阶段不加入校园行走、导师关系、社交、经费、课程或完整多年生涯。只有在一学年纵切片本身可重复游玩后，才评估这些系统。
