# 《博三之前》核心玩法重设计 V1：从"填进度条"到"做决策"

版本：Redesign V1.0  
日期：2026-07-30  
状态：设计草案，待评审  
目标：诊断并修复"不好玩"的根本问题，重新设计 moment-to-moment 核心循环

---

## 0. 设计目标

改造后，玩家在每回合应该经历以下情绪循环：

> "操，截稿提前了？" → "我还有这张牌可以应对" → "赌一把，用高风险方法冲刺" → "漂亮！连锁触发，一举两得" → "还有3周，继续冲还是安全撤？"

而不是：

> "这周打调查牌" → "证据+1" → "下周打实验牌" → "证据+1"

---

## P1. 核心改造：从"玩家主导"到"双向博弈"

### P1.1 新增：学术危机系统（Dynamic Opposition）

每一周开始，玩家从"学术危机牌堆"抽1张危机牌。危机牌不是"坏运气惩罚"，而是**制造决策压力的游戏内容**。

#### 危机牌堆结构（首发16张）

**截稿类（4张）**：操控时间压力
| 危机 | 效果 | 持续时间 |
|---|---|---|
| 提前截稿 | 投稿窗口缩短2周 | 本周期永久 |
| 延期通知 | 投稿窗口延长1周，但压力+1 | 本周期永久 |
| 导师催稿 | 本周必须使用1个行动点推进课题，否则压力+2 | 本周 |
| 返修截止 | 立即可选：立即投稿（当前状态）或接受审稿意见补实验 | 即时 |

**竞争类（4张）**：威胁课题价值
| 危机 | 效果 | 持续时间 |
|---|---|---|
| 抢先发表 | 选一个课题，其"新颖性"进度卡锁死（无法完成），需替换研究方向 | 本周期 |
| 横向对标 | 要求课题必须完成"对标基线"进度卡才能投稿 | 本周期 |
| 审稿人偏见 | 本期投稿增加1个额外要求 | 本周期 |
| 领域降温 | 本期投稿的收益降低一档 | 本周期 |

**设备/资源类（4张）**：限制策略空间
| 危机 | 效果 | 持续时间 |
|---|---|---|
| 设备宕机 | 实验类方法牌本周不可用 | 本周 |
| 数据损毁 | 随机一项已完成的"数据类"进度卡变回未完成 | 即时 |
| 经费冻结 | 下张打出的"设备/消耗"类牌精力成本+1 | 下次 |
| 合作方退出 | 移除一个跨课题协同效果 | 本周期 |

**导师/人际类（4张）**：引入外部变量
| 危机 | 效果 | 持续时间 |
|---|---|---|
| 紧急任务 | 本周必须使用1张牌在"导师项目"上，否则压力+1 且 下周少抽1张 | 本周 |
| 学术会议冲突 | 选一个课题接受"会议Demo展示"（提前结算部分成果），或放弃展示（声望-1） | 即时 |
| 伦理审查 | 选一个课题暂停1周接受审查，或继续推进但压力+2 | 本周 |
| 学生抗议 | 本周所有方法牌的精力成本+1 | 本周 |

#### 危机设计原则
- 每张危机都提供**至少2种应对方式**（硬扛/绕路/妥协）
- 危机不能直接判负（不出现"抽到XX就必输"）
- 危机比例：60%制造选择困难，30%可用特定方法牌克制，10%纯压力
- 每周期首周保证给1张"温和"危机（不锁死核心动作）

### P1.2 改造：课题从"属性条"变为"进度卡拼图"

#### 旧设计
```
课题 = {证据: 3, 完成度: 4, 风险: [理论风险B, 未验证]}
```
玩家做的事：让数字变大。

#### 新设计
```
课题 = 一组"研究进度卡"（Research Milestones）
每张进度卡有：
  - 名称：文献综述 / 消融实验 / 对标基线 / 图表叙事 / 方法创新
  - 状态：未开始 / 进行中 / 已完成
  - 所需方法标签：[调查] [实验] [组织] 等
  - 前置条件：可能需要其他进度卡先完成
  - 完成后效果：不只是"完成度+1"，而是产生具体影响
```

#### 首发8张进度卡模板

| 进度卡 | 所需标签 | 前置 | 完成后效果 |
|---|---|---|---|
| 文献综述 | [调查] | 无 | 揭示1个隐藏风险 |
| 基础数据 | [实验] [组织] | 无 | 解锁下一级实验型进度卡 |
| 消融实验 | [实验] | 基础数据 | 可将1个风险从"未验证"降为"已控制" |
| 对标基线 | [实验] [组织] | 基础数据 | 提高投稿后的论文评分+1档 |
| 方法创新 | [组织] [写作] | 文献综述 | 解锁"优秀投稿"资格 |
| 图表叙事 | [写作] | 消融实验 或 对标基线 | 使"提交投稿"可用 |
| 补充验证 | [实验] [生存] | 消融实验 | 应对"审稿危机"时自动生效 |
| 理论框架 | [调查] [写作] | 文献综述 | 降低整体风险等级1档 |

#### 为什么这样更好？

1. **视觉化**：玩家看到拼图一块块填满，比数字增长满足感强10倍
2. **有意义的选择**："先做消融实验降低风险，还是先做对标基线冲高分？" vs "要不要让证据+1？"
3. **策略深度**：进度卡的前置条件 = 天然的路线规划
4. **更好的反馈**：每完成一张进度卡 = 一个"爽点"，而不是累积的数字变化

## P2. 卡牌系统重设计：从"+1按钮"到"效果引擎"

### P2.1 卡牌新设计原则

**每张卡必须至少满足一项：**
1. 改变规则（而非数值）
2. 产生连锁反应
3. 提供二择一选择
4. 与特定进度卡/危机/风险产生独特交互

**禁止设计的卡：**
- 纯数值加成的卡（`证据+1` 不是一张卡，是一个效果）
- 与现有卡功能重叠的卡（功能相同只改数值 = 垃圾卡）
- 无条件永远最优的卡（没有代价的强卡 = 无脑选择）

### P2.2 卡牌效果类型

重构后的方法牌使用以下效果分类：

#### A类：推进型（推进进度卡）
```
例：「系统综述」
效果：推进目标课题的一个[调查]标签进度卡。
      如果你本周已使用过另一张调查牌，连锁：额外推进1格。
```
不再"证据+1"。而是"把这张进度卡做完"。

#### B类：风险操作型（操控风险状态）
```
例：「预实验验证」
效果：选择1个已揭示的风险，进行一次验证掷骰。
     【低风险】自动消除  【中风险】80%消除  【高风险】40%消除
     失败时：获得"风险认知"（下次同类风险成功率+20%）
```
加入可控的随机性。不是"投隐藏骰决定成败"，而是"赌一把是否提前消除风险"。

#### C类：连锁/协同型（创造额外价值）
```
例：「交叉验证」
效果：选择一个已完成进度卡。
      如果该进度卡与当前目标课题的未完成进度卡存在共同标签，
      立即推进该未完成进度卡1格。
```
鼓励多课题协同，不只是 tag 匹配。

#### D类：危机响应型（对抗动态对手）
```
例：「预投稿」
效果：本周抽到的危机牌延迟到下周生效。
      但下周必须额外处理1张危机。
```
给你喘息空间，但代价是更大的压力。

#### E类：构筑规则型（改变本局规则）
```
例：「夜间模式」
效果：本周剩余所有方法的精力成本-1，但压力+1。
      此效果持续到本周结束。
```
这些牌定义你的"流派"，而非简单加数值。

### P2.4 卡牌获取与牌组管理

- 开局：固定8张基础牌组
- 每周期第2、4周：三选一加入
- 牌组上限：12张（超出必须替换）
- 遗产：成功/失败获得1张特殊牌，下局直接在手牌中
- 不再有"通用强牌"：每张牌在不同构筑中的价值差异很大

## P3. 搜打撤心理循环重设计

### P3.1 核心张力公式

```
当前课题价值 = (已完成进度卡数 × 投稿窗口加成) ÷ (剩余时间 × 风险暴露度)

当 课题价值 > 安全撤出收益 时 → 继续深入
当 课题价值 < 安全撤出收益 时 → 撤出
当 课题价值 ≈ 安全撤出收益 时 → 玩家犹豫 = 游戏成功
```

### P3.2 可视化张力

**深入刻度条**：每个课题有一个"深入度"指示器
```
课题A: ████████░░ 深入度 8/10
        ▲ 安全撤出线（6）
        超过6后撤出，保留的资产大幅减少
        达到10后必须投稿
```

每当你推进一格课题，深入度+1。深入度越高：
- 完成课题后的**收益越高**（高分论文）
- 撤出后的**损失越大**（越接近完成越不甘心撤）
- 暴露的**新风险越多**（深入后发现更复杂的问题）

### P3.3 撤出（Extract）的三种模式

旧设计中"撤出"只有一种方式。新的设计：

| 撤出方式 | 触发条件 | 保留资产 | 代价 |
|---|---|---|---|
| 安全撤出 | 深入度 ≤ 安全线 | 全部已完成进度 + 全部风险认知 | 无投稿收益 |
| 紧急撤出 | 深入度 > 安全线 | 50%已完成进度（随机） | 压力+2，声望-1 |
| 强制中止 | 倒计时归零 / 精力崩溃 | 仅保留风险认知 | 压力+3，周期内不得再用此课题 |

**撤出不是失败**——安全撤出是一个完全合理的策略选择（尤其在危机叠加时）。

### P3.4 周期末"兑现"阶段

不再只是"检查数值 → 通过/失败"。投稿变成一个小型高潮：

```
投稿阶段：
1. 展示你已完成的所有进度卡（拼图可视化）
2. 展示未处理的风险和危机影响
3. 给出最终评价：
   - 完成度（多少进度卡完成/需求）
   - 风险控制度（多少风险已控制/总数）
   - 危机应对度（多少危机被化解/总数）
4. 三个维度组合 = 最终评分（优秀/良好/及格/失败）
5. 每个维度的评价产生具体的反馈文字
```

## P4. 经济与平衡设计

### P4.1 资源流模型

```
每周输入：精力回满（基础6） + 抽牌3张 + 抽危机1张

每周消耗：打牌（精力1-3/张）+ 危机副作用

每周产出：进度卡推进 + 风险状态变化

关键平衡点：
- 6精力 ÷ 4行动点 = 平均每张牌1.5精力成本
- 一局6周 = 24行动点
- 完成一个课题约需8-12行动点（取决于风险和危机）
- 双课题同时推进约需16-20行动点
- 剩余4-8行动点用于危机应对和调整
```

### P4.2 进度卡经济学

```
课题总进度卡数：5-7张
投稿最低要求：4张完成 + 至少1个[写作]进度卡
优秀投稿要求：全部完成 + 所有风险已控制

单张[调查]卡完成成本：平均1.5张方法牌
单张[实验]卡完成成本：平均2张方法牌（含风险验证）
单张[写作]卡完成成本：平均1.5张方法牌
单张[组织]卡完成成本：平均1张方法牌

一个课题理论最低成本：6方法牌（全最优路线）
一个课题实际平均成本：10-12方法牌（含风险处理）
```

### P4.3 压力曲线

```
压力值 | 效果
0-2    | 正常
3-4    | 每周手牌上限-1（抽2张）
5-6    | 每周额外抽1张危机
7      | 精力上限-1，本周无法使用[协作]类型牌
8      | 强制休假1周（本周只能使用生存牌）
```

设计意图：压力不是"血条"，而是"污染器"。压力升高让你的决策空间收窄、不确定性增加，但不会直接判负。

### P4.4 平衡核心假设

```
[PLACEHOLDER] 以下数值均为设计假设，需真人试玩后校准：

- 新手首局通关率（及格以上）：60-70%
- 有经验玩家通关率（优秀）：25-35%
- 专家玩家多课题优秀率：15-20%
- 危机导致路线变更的比例：40-50%
- 玩家使用"撤出"策略的比例：20-30%
- 平均每局经历2.5次"深入/撤出"犹豫
- 无单一最优构筑（任何流派胜率差不超过20%）
```

## P5. 流派构筑设计

### P5.1 三种核心流派

**理论派（信息掌控）**
- 核心牌：系统综述、深度引用、专家咨询、证据链整理
- 节奏：前期慢，风险透明，后期稳
- 弱点：速度慢，容易错过窗口
- 爽点：所有风险一目了然，投稿信心十足

**冲刺派（高风险高回报）**
- 核心牌：通宵冲刺、参数扫描、预投稿、数据伪造、文献速读
- 节奏：快速推进，但压力飙升
- 弱点：压力管理难度大，容易崩溃
- 爽点：在截稿前奇迹般完成，玩的是心跳

**协同派（多课题联动）**
- 核心牌：合作邀请、证据链整理、交叉验证、负结果转化
- 节奏：中等，双课题并行推进
- 弱点：需要更多行动点，受危机影响更大
- 爽点：方法链触发，一个行动推进两个课题

### P5.2 流派平衡指标


## P6. 反馈系统设计

### P6.1 每回合必须回答的四个问题

每个行动后，UI必须明确展示：
1. **改变了什么？** - 进度卡推进了、风险被控制了、危机被化解了
2. **代价是什么？** - 精力消耗、压力增加、时间流逝
3. **连锁了什么？** - 协同触发、隐藏效果激活
4. **接下来多了/少了什么选择？** - 打开/关闭了什么可能性

### P6.2 关键反馈时刻

| 时刻 | 反馈 | 情绪目标 |
|---|---|---|
| 完成一张进度卡 | 卡牌翻转动画 + 音效 + "里程碑达成" | 成就感 |
| 风险验证成功 | 风险标记从🔴变🟢 + 压力短暂释放动画 | 释然 |
| 风险验证失败 | 风险等级上升 + 新的连锁问题出现 | "该死，现在怎么办" |
| 危机化解 | 危机牌被撕碎动画 | 爽感 |
| 连锁触发 | 两个课题同时推进的视觉特效 | 构筑满足感 |
| 截稿倒计时归零 | 屏幕边缘红光 + 时间到音效 | 紧张 |
| 投稿成功 | 论文盖章动画 + 结算画面 | 成就高潮 |
| 安全撤出 | 资产"打包入库"动画 | 战略性满足 |

## P8. 开发优先级

### 阶段A：核心验证（2-3周）—— 最高的优先级
1. 实现进度卡（Milestone）系统替代数值模型
2. 实现18张新方法牌效果引擎
3. 实现危机系统核心逻辑
4. 实现新的周循环（危机→抽牌→行动→结算）
5. 基于 Seed 的确定性保证

**验收标准：**
- 1个课题 + 5张进度卡 + 6张方法牌的闭环可玩
- 真人玩家能在3分钟内完成一局并理解为什么赢/输
- 3个不同 Seed 产生3种不同的策略选择

### 阶段B：深度与平衡（2-3周）
1. 双课题 + 协同机制
2. 卡牌获取与牌组管理
3. 搜打撤深度可视化
4. 平衡调优（真人试玩数据驱动）

### 阶段C：反馈与美术（2周）
1. 进度卡翻转动画
2. 危机/风险视觉反馈
3. 投稿结算演出
4. 压力可视化

## P9. 关键验收指标（真人试玩）

### 可理解性
- 80% 新玩家无指导完成首周期
- 75% 能解释"为什么输/赢"
- 70% 能说出自己选择的流派

### 有趣性 ← 新增核心指标
- 60% 玩家在"深入/撤出"时产生真实犹豫
- 50% 玩家对至少1张危机牌说"有意思"而非"真烦"
- 每次试玩后至少1个"你没想到他会这么做"的行为
- 玩家自发讨论卡牌组合（而非讨论系统架构）

### 可重复性
- 3局内出现3种不同的策略路线
- 无固定最优解（任何卡的选取率不超过80%）
- 危机系统导致至少30%的局"偏离原计划"

## 附录：新旧设计对比速查

| 维度 | 旧设计 | 新设计 |
|---|---|---|
| 核心动作 | 打牌→数值+1 | 打牌→推进进度卡/操控风险/化解危机 |
| 课题表现 | `{证据:3, 完成度:4}` | 5-7张进度卡拼图 |
| 动态对抗 | 无 | 每周1张危机牌 |
| 卡牌效果 | "+1"为主 | 规则改变/连锁/二择 |
| 搜打撤 | 撤出=放弃 | 撤出=策略选择，三种方式 |
| 反馈 | 数字变化 | 进度卡翻转、动画、音效 |
| 随机性 | 0（完全确定） | 可控随机（验证掷骰） |
| 单局时长 | 10-15分钟 | 12-18分钟（更充实） |
| 流派 | 模糊 | 理论/冲刺/协同 三派 |
| 压力机制 | 抽牌变少 | 决策空间收窄 |
