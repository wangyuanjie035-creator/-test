# 核心循环

## 单局流程

1. 选择开局身份、导师、实验室或研究方向。
2. 进入学期地图，选择节点。
3. 节点可能是普通压力、学术事件、实验室事件、商店、休整、导师沟通或阶段考核。
4. 回合制卡牌战斗中积累研究进度，处理压力和负面状态。
5. 通过阶段 Boss 后进入下一学历阶段。
6. 触发毕业、延毕、转行、休学、失败或隐藏结局。
7. 结算本局履历，转化为局外资源。
8. 解锁新卡、新导师、新身份、新事件或前辈传承。

## 阶段结构

| 阶段 | 主题 | 主要压力 | 阶段 Boss |
| --- | --- | --- | --- |
| 研一 | 适应、课程、找方向 | 信息过载、导师期待、文献陌生 | 开题报告 |
| 研二 | 实验、数据、组会 | 进度不足、实验失败、方向摇摆 | 中期考核 |
| 研三 | 投稿、毕业条件 | 小论文、查重、就业压力 | 毕业资格审查 |
| 博一 | 重建课题和身份 | 方向重构、科研深水区 | 博士开题 |
| 博二 | 论文主线成型 | 大修返稿、项目压力、合作摩擦 | Reviewer #2 |
| 博三 | 盲审与答辩 | 时间耗尽、成果不足、心理压力 | 盲审与答辩 |
| 博四及以后 | 延毕线 | 同届毕业、经费压力、长期疲劳 | 毕业只差一点 |

## 核心资源

| 资源 | 作用 | 归零或过高后果 |
| --- | --- | --- |
| 精力 | 类似生命值，承受压力和返工 | 归零可能休学、崩溃或进入坏结局 |
| 行动点 | 每回合打牌费用 | 每回合刷新 |
| 研究进度 | 推进当前敌人或阶段目标 | 达标后通过节点 |
| 灵感 | 支付高阶研究牌、理论牌或论文牌 | 稀缺资源，鼓励构筑 |
| 数据 | 论文和实验卡的关键材料 | 数据不足会卡住论文牌 |
| 草稿 | 论文写作材料 | 可转化为投稿、综述或答辩材料 |
| 经费 | 购买设备、参加会议、外包测试 | 经费不足限制资源流 |
| 声望 | 影响审稿、合作和导师评价 | 声望低时部分事件更难 |
| 心理韧性 | 抵抗焦虑、拖延和自我怀疑 | 低韧性更容易获得负面牌 |
| 伦理值 | 约束高风险捷径 | 过低触发学术风险结局 |

## 回合制战斗定位

战斗不是传统打怪，而是处理一个学术压力或阶段挑战。敌人代表事件、任务或制度压力。

例子：

- 第一次组会。
- 实验失败。
- 导师临时改方向。
- 师兄留下的祖传代码。
- 设备排队。
- 审稿意见。
- 盲审专家。

玩家的卡牌不是攻击与防御的简单换皮，而是通过文献、实验、写作、沟通、休息、设备和导师资源来推进研究进度并保护自身状态。

## 节点类型

| 节点 | 功能 |
| --- | --- |
| 普通压力 | 标准战斗，给予卡牌或资源奖励 |
| 精英压力 | 高难节点，奖励强力遗物或导师好感 |
| 阶段考核 | Boss 节点，决定是否升阶 |
| 事件 | 随机校园、实验室、投稿或生活事件 |
| 休整 | 恢复精力、移除负面牌、升级卡牌 |
| 导师沟通 | 调整方向、获得资源、承担额外任务 |
| 实验室 | 购买设备、维修设备、升级设施 |
| 会议 | 消耗经费，获得声望、人脉或合作牌 |

## 失败状态

失败应有明确原因和对应正反馈：

| 失败原因 | 结局表达 | 可转化收获 |
| --- | --- | --- |
| 精力归零 | 休学或崩溃 | 心理韧性、照护类开局能力 |
| 毕业条件不足 | 延毕 | 延毕线卡牌、前辈传承 |
| 论文连续拒稿 | 投稿失败 | 审稿经验、论文碎片 |
| 课题失败 | 方向重开 | 方法论笔记、负结果卡 |
| 伦理值过低 | 学术风险 | 伦理警示、风险识别 |
| 经费断裂 | 项目停摆 | 资源管理解锁、低经费路线 |

## 正反馈节奏

每局至少应提供三层正反馈：

- 回合内：打出连携、获得数据、爆发推进。
- 节点后：选卡、升级、拿遗物、移除负面牌。
- 单局后：履历结算、永久解锁、前辈传承。

坏结局后的结算界面需要强调“你留下了什么”，避免玩家只看到失败。
