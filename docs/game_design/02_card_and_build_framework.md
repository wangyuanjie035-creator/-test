# 卡牌与构筑框架

## 卡牌类型

| 类型 | 定位 | 示例 |
| --- | --- | --- |
| 行动牌 | 当回合立即生效 | 精读文献、通宵赶稿、复现实验 |
| 技能牌 | 防御、整理、回复、过滤牌库 | 调整作息、整理 Zotero、请教师兄 |
| 论文牌 | 需要数据或草稿，提供阶段性大收益 | 会议短文、一作长文、综述论文 |
| 方向牌 | 定义构筑底层规则 | 深度学习、材料合成、理论推导 |
| 导师牌 | 长期规则或特殊技能 | 放养型导师、高压型导师、资源型导师 |
| 实验室牌 | 场地或设施加成 | GPU 集群、共享服务器、老旧离心机 |
| 设备牌 | 可使用或可充能的工具 | 显微镜、服务器、问卷平台 |
| 合作牌 | 社交、人脉、共同作者 | 跨校合作、找师兄问问、会议偶遇 |
| 调适牌 | 心理韧性和恢复 | 摸鱼半天、运动一下、看淡一切 |
| 风险牌 | 高收益高副作用 | 数据清洗捷径、极限ddl、硬刚审稿人 |
| 负面牌 | 污染牌库或造成副作用 | 拖延、焦虑、不可复现、导师未读 |

## 关键词草案

| 关键词 | 含义 |
| --- | --- |
| 灵感 | 获得或消耗高阶研究资源 |
| 数据 | 论文牌和实验牌的材料 |
| 草稿 | 写作材料，可转化为论文进度 |
| 返工 | 本回合或下回合加入负面牌 |
| 熬夜 | 强力效果，但失去精力 |
| 共鸣 | 若本回合已打出同类牌，触发额外效果 |
| 复现 | 若上一次实验成功，获得额外数据 |
| 投稿 | 消耗草稿和数据，进行一次收益判定 |
| 大修 | 暂时降低收益，但完成后升级论文牌 |
| 放养 | 减少导师干预，增加自由灵感 |
| 高压 | 提高进度收益，同时增加压力伤害 |
| 延毕 | 在博四及以后获得额外效果 |
| 照护 | 回复精力或心理韧性 |
| 伦理风险 | 降低伦理值，可能触发严重后果 |

## 费用和升级

卡牌默认使用行动点费用，部分高阶牌还需要灵感、数据、草稿或经费。

升级方向可以分为：

- 降低费用。
- 增加进度或防护。
- 减少副作用。
- 增加抽牌或检索。
- 改变关键词，例如普通实验升级为可复现实验。

## 构筑流派

### 文献灵感流

核心体验：通过精读文献、综述、理论框架和检索不断抽牌和生成灵感。

优势：稳定、后期强、适合理论和交叉方向。

弱点：前期推进慢，怕时间限制和直接实验要求。

### 实验数据流

核心体验：用设备、实验室和复现机制堆数据，再用论文牌转化为成果。

优势：数据质量高，论文爆发强。

弱点：怕设备损坏、样本污染和不可复现。

### 卷王爆发流

核心体验：用熬夜、ddl、连续实验换取高速进度。

优势：前中期推进极快。

弱点：精力消耗大，坏状态多。

### 设备资源流

核心体验：通过经费、实验室设施和设备牌形成稳定生产线。

优势：资源越滚越强。

弱点：启动慢，怕经费冻结和设备维修。

### 社交合作流

核心体验：通过会议、人脉、师兄师姐和合作项目获得灵活卡牌。

优势：选择多，能化解很多事件。

弱点：成果归属不稳定，可能获得沟通成本。

### AI 调参流

核心体验：抽牌、复制、自动化、算力爆发。

优势：爆发强，操作感好。

弱点：怕过拟合、数据泄漏、算力不足。

### 抗压延毕流

核心体验：不把延毕视为失败，而是把长期积累转化为特殊力量。

优势：后期韧性强，坏结局收益高。

弱点：前期难成型，需要承受压力。

## 初始卡组草案

MVP 可从一个通用研究生初始牌组开始：

| 卡牌 | 数量 | 作用 |
| --- | --- | --- |
| 查文献 | 4 | 获得少量灵感或抽牌 |
| 做实验 | 4 | 获得研究进度，概率获得数据 |
| 写草稿 | 3 | 获得草稿 |
| 自我调整 | 3 | 获得心理韧性或少量防护 |
| 请教前辈 | 1 | 发现一张行动牌 |

后续再让开局身份、导师和方向替换部分初始牌。
