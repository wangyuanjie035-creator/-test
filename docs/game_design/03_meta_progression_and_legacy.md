# 局外成长与师门传承

## 设计目标

局外成长要让玩家觉得每一局都有价值，但不能把后期变成纯数值碾压。优先解锁新选择、新路线、新事件和新叙事身份，少给直接永久属性加成。

## 履历结算

每局结束后生成一份“学术履历”。履历记录：

- 本局最高阶段。
- 主要导师和研究方向。
- 完成的论文、实验、会议和项目。
- 失败原因或毕业类型。
- 获得的局外资源。
- 可能转化成前辈的角色身份。

## 局外资源

| 资源 | 来源 | 用途 |
| --- | --- | --- |
| 经验教训 | 任意结局 | 解锁通用卡、事件、开局选项 |
| 论文碎片 | 投稿、拒稿、接收、大修 | 解锁论文牌和审稿相关遗物 |
| 方法论笔记 | 实验、理论、调研、代码 | 解锁研究方向强化 |
| 人脉 | 会议、合作、师兄师姐 | 解锁合作牌和开局支援 |
| 心理韧性 | 高压、休学、延毕、崩溃边缘 | 解锁调适牌和保护能力 |
| 设备蓝图 | 实验室、项目、经费 | 解锁设备牌和实验室设施 |
| 黑历史档案 | 坏结局、重大事故 | 解锁特殊事件线和风险提示 |

## 坏结局奖励

| 坏结局 | 解锁方向 |
| --- | --- |
| 论文连续被拒 | 审稿人雷达、返修经验、转投策略 |
| 实验事故 | 安全培训证书、实验失败补偿 |
| 导师关系破裂 | 独立研究者、自由方向牌 |
| 博四延毕 | 看淡一切、老博士经验、延毕关键词 |
| 数据不显著 | 负结果也是结果、方法论笔记加成 |
| 退学转行 | 产业合作、企业前辈、工程项目线 |
| 休学恢复 | 自我照护、心理韧性保护 |
| 学术风险暴雷 | 伦理警示、风险识别事件 |

学术不端类结局不应给强力数值奖励，避免鼓励玩家主动走坏路线。它更适合解锁风险提示、伦理事件和反作弊系统。

## 师门传承

每局角色结束后，可以以一种前辈身份留在后续局中。

| 上一局结局 | 下一局可能出现的前辈 |
| --- | --- |
| 正常毕业 | 靠谱师兄或师姐 |
| 优秀毕业 | 学术新星 |
| 顶刊毕业 | 大佬前辈 |
| 延毕毕业 | 传奇老博士 |
| 转行 | 企业前辈 |
| 休学恢复 | 温柔提醒 |
| 课题失败 | 避坑笔记作者 |

前辈不一定永久强力，最好提供带性格的选择。例如“传奇老博士”可以给强力延毕卡，但也可能带来额外拖延牌。

## 解锁原则

- 解锁新玩法优先于永久加数值。
- 坏结局奖励应与失败原因相关。
- 玩家应该能在结算界面看懂“为什么我获得了这个”。
- 解锁不应要求玩家故意刷痛苦，正常游玩也能自然获得。
- 每次结算至少给一个可感知收获。

## 示例局外能力

| 能力 | 效果 |
| --- | --- |
| 自我照护 | 每局第一次精力低于阈值时恢复少量精力 |
| 审稿人雷达 | 每场 Boss 战第一次显示额外意图信息 |
| 负结果也是结果 | 实验失败时有概率获得方法论笔记 |
| 安全培训证书 | 第一次实验事故事件无效 |
| 老博士经验 | 进入延毕阶段时获得一张特殊卡 |
| 企业联系人 | 会议节点有概率出现产业合作选项 |

这些能力都应可配置开关或有装备槽限制，避免解锁越多越无脑。
