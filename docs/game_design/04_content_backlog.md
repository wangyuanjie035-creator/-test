## 负面牌候选

| 名称 | 效果方向 |
| --- | --- |
| 拖延 | 抽到时占手牌，可花费行动点移除 |
| 焦虑 | 回合结束失去心理韧性 |
| 数据不显著 | 降低下一张论文牌收益 |
| 不可复现 | 阻碍实验连携 |
| 代码跑不通 | 禁用一张 AI 或工程牌 |
| 样本污染 | 丢失数据 |
| 导师未读 | 导师牌暂时失效 |
| 格式错误 | 投稿或答辩前增加额外要求 |
| 查重警告 | 降低伦理或声望 |
| 组会阴影 | 遇到组会类敌人时额外受压 |

## 事件候选

| 名称 | 选择方向 |
| --- | --- |
| 食堂偶遇大牛 | 获得方向启发，或花费声望建立联系 |
| 导师让你写基金本子 | 获得经费机会，但加入行政杂务 |
| 设备坏了 | 花费经费维修，或短期禁用设备牌 |
| 论文被拒 | 转投、重修、换方向三选一 |
| 招新来了师弟师妹 | 获得助手，也可能获得带新人负担 |
| 学院讲座 | 获得灵感、声望或睡眠不足 |
| 国际会议 | 消耗经费，获得人脉、声望和合作牌 |
| 导师跳槽 | 保持原方向、跟随导师或换导师 |
| 家庭事件 | 恢复心理韧性，但消耗时间 |
| 同门毕业 | 获得压力，也可能获得前辈传承 |

## Boss 候选

| Boss | 机制方向 |
| --- | --- |
| 开题报告 | 检查研究方向与初始数据，施加自我怀疑 |
| 中期考核 | 每数回合检查进度，不足则加入延期警告 |
| 小论文要求 | 需要论文牌或声望，否则压力递增 |
| Reviewer #2 | 高反驳、高返工，针对核心论文牌 |
| 基金截止日期 | 倒计时 Boss，越拖越强 |
| 盲审专家 | 免疫低质量话术，需要扎实数据和创新点 |
| 答辩委员会 | 多阶段 Boss，考察论文、表达和心理韧性 |
| 毕业只差一点 | 延毕 Boss，反复制造临门一脚的阻碍 |

## 结局候选

| 结局 | 条件方向 |
| --- | --- |
| 正常毕业 | 达成基础论文、答辩和心理状态要求 |
| 优秀毕业 | 高声望、高质量成果、低伦理风险 |
| 顶刊博士 | 完成高难论文线 |
| 延毕归来 | 博四或以后完成毕业 |
| 转行上岸 | 选择产业、考公或创业路线 |
| 休学恢复 | 精力或心理韧性归零后进入恢复线 |
| 课题重开 | 方向完全崩溃但保留方法论 |
| 学术风险 | 伦理值过低 |
| 留校任教 | 声望、人脉和论文同时高 |
