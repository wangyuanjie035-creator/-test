## 5. 精力经济

### 方法牌精力成本分布（18张）
| 精力成本 | 张数 | 占比 | 示例 |
|---|---|---|---|
| 0 | 4张 | 22% | 战略暂停、文献速读、预投稿 |
| 1 | 9张 | 50% | 系统综述、数据清洗、专家咨询 |
| 2 | 3张 | 17% | 消融分析、图表重构、参数扫描 |
| 3 | 2张 | 11% | 通宵冲刺、数据伪造（高风险） |

### 每周精力预算
```
总精力: 6 (上限)
每周行动点: 4

最优分配（标准周）:
- 2张1费牌 + 1张2费牌 = 4精力, 3行动点
- 剩余1行动点用于0费牌或跳过

爆发周（通宵冲刺激活后）:
- 所有牌成本-1 → 4张牌 = 4精力
- 但压力+2，下周可能面临崩溃

紧张周（危机叠加）:
- 只能打3张牌（精力限制）
- 必须做出取舍
```

### 精力恢复

|---|---|---|

| 生存牌：战略暂停 | +2 | 1行动点，不能推进 |
| 数据清洗卡 | +1 | 正常打出附带效果 |

## 8. 流派平衡目标

| 流派 | 目标胜率（及格以上） | 目标优秀率 | 平均压力终值 |
|---|---|---|---|
| 理论派 | 55-65% | 20-30% | 2-4 |
| 冲刺派 | 45-55% | 35-50% | 5-7 |
| 协同派 | 50-60% | 25-35% | 3-5 |

**平衡原则：**
- 理论派胜率最高（稳健），但优秀率最低（上限低）
- 冲刺派胜率最低（赌博），但优秀率最高（上限高）
- 协同派中间路线
- 任何两流派胜率差不超过20%

- 中等危机：60-70%能被有效应对
- 严重危机：30-40%能完全化解，但60%可通过"妥协路线"接受部分损失

## 10. 试玩验证的"broken"定义

以下是判断系统是否"坏了"的标准：

### 经济破裂
- [ ] 某个资源（精力/压力/行动点）在超过40%的局中从未成为约束
- [ ] 存在无限循环（免费精力恢复 = 永远不会精力归零）
- [ ] 某个构筑在所有Seed中都能碾压其他构筑（胜率差>30%）

### 决策失效
- [ ] 超过70%的局中，"中期判断"选择完全相同（无真实分歧）
- [ ] "撤出"在任何Seed中都不是最优策略（永远是错的）
- [ ] 某个行动在所有局面下都优于其他行动（统治策略）

### 反馈失效
- [ ] 玩家无法在3秒内理解本周发生了什么
- [ ] 投稿失败时，玩家说不出哪个决策导致了失败
- [ ] 超过30%的局在结算前已被玩家预知结果（无悬念）

### 乐趣失效
- [ ] 连续3局后，玩家没有任何"这次我要换个打法"的冲动
- [ ] 危机牌出现时，玩家的第一反应是"真烦"而非"怎么应对"
- [ ] 完成一张进度卡时，玩家没有感到任何满足

## 附录：调优流程

```
1. 设定目标值（本表）
2. 内部试玩 → 记录数据
3. 对比目标值 → 识别偏离
4. 调整单一参数（每次只改1个！）
5. 再次试玩 → 验证效果
6. 重复直到进入目标区间
7. 新人盲测 → 确认可理解性
```

**调优铁律：一次只改一个参数。** 同时调两个参数你永远不知道哪个起了作用。
