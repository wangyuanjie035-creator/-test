## 事件设计原则

MVP 事件要服务三个目标：

- 提供战斗之外的研究生味道。
- 给玩家一次明确取舍，而不是纯随机奖励。
- 和局外成长、坏结局正反馈建立连接。

## E001 食堂偶遇大牛

出现阶段：研一及以后

主题：方向启发、人脉、机会成本

描述：你在食堂排队时听到隔壁桌的大牛正在讨论一个和你课题相关的问题。

| 选项 | 条件 | 结果 |
| --- | --- | --- |
| 凑过去请教 | 无 | 失去 3 精力，获得 2 灵感，获得 1 声望 |
| 默默记下关键词 | 无 | 获得 1 灵感，下一场战斗开局抽 1 张牌 |
| 递上自己的草稿 | 需要 2 草稿 | 消耗 2 草稿，获得 1 声望，发现 1 张论文牌 |
| 假装没听见 | 无 | 恢复 2 精力 |

设计意图：让玩家在精力、灵感、声望之间做轻量选择。

## E002 导师让你写基金本子

出现阶段：研一及以后

主题：经费、行政杂务、导师关系

描述：导师突然说：“这个本子你先帮我起个草稿，明天上午给我。”

| 选项 | 条件 | 结果 |
| --- | --- | --- |
| 立刻答应 | 无 | 获得 2 经费和 1 声望，将 1 张“行政杂务”加入牌组 |
| 争取署名和资源 | 需要 1 声望 | 获得 2 经费，发现 1 张设备牌 |
| 委婉拒绝 | 无 | 恢复 4 精力，下一场 Boss 开局受到 4 压力 |
| 用旧模板糊一下 | 伦理风险 | 获得 2 经费，伦理值 -1，将 1 张“格式错误”加入牌组 |

设计意图：让资源增长和负担绑定，并展示伦理风险不是免费捷径。

## E003 设备坏了

出现阶段：研二及以后

主题：经费、实验路线、替代方案

描述：你预约了很久的设备突然报修，管理员说最快也要下周。

| 选项 | 条件 | 结果 |
| --- | --- | --- |
| 花钱维修 | 需要 2 经费 | 消耗 2 经费，获得 1 数据，将 1 张 `C014 清理实验台` 加入牌组 |
| 找隔壁实验室借 | 需要 1 声望 | 获得 1 数据，将 1 张 `C023 请教师兄` 加入牌组 |
| 改做理论分析 | 无 | 获得 2 灵感，将 1 张 `S003 不可复现` 加入牌组 |
| 抢窗口继续跑 | 无 | 失去 3 精力，获得 1 数据，将 1 张 `S009 样本污染` 加入牌组 |

设计意图：验证设备资源流和文献灵感流都能处理突发状况。

## E004 论文被拒

出现阶段：研二及以后

主题：坏消息、重投、局外正反馈

描述：邮箱里弹出新邮件，标题只有几个字：“Decision on your manuscript”。

| 选项 | 条件 | 结果 |
| --- | --- | --- |
| 转投稳妥期刊 | 无 | 获得 1 论文碎片和 1 声望，下一张论文牌进度 -4 |
| 大修重投 | 需要 2 草稿 | 消耗 2 草稿，升级 1 张论文牌，将 1 张“返修”加入牌组 |
| 换一个叙事角度 | 需要 2 灵感 | 消耗 2 灵感，移除 1 张负面牌，发现 1 张文献牌 |
| 破防一天 | 无 | 失去 4 精力，获得 2 经验教训 |

设计意图：把拒稿变成可恢复、可转化的系统事件。

## E005 师兄毕业交接

出现阶段：研一到研三

主题：师门传承、祖传资源、副作用

描述：师兄答辩通过，临走前把一个硬盘和一堆“应该能跑”的脚本交给你。

| 选项 | 条件 | 结果 |
| --- | --- | --- |
| 接过祖传硬盘 | 无 | 获得 1 数据和 1 张“调试脚本”，将 1 张“代码跑不通”加入牌组 |
| 只要实验记录 | 无 | 获得 1 方法论笔记，获得 1 灵感 |
| 请师兄吃饭细聊 | 需要 1 经费 | 消耗 1 经费，获得 1 人脉，升级 1 张合作牌 |
| 保持独立 | 无 | 获得 1 声望，下一场战斗开局少抽 1 张牌 |

设计意图：为后续师门传承系统提前埋入口。

## 事件纸面测试关注点

- 每个事件是否至少有两个合理选择。
- 事件奖励是否会推动玩家构筑，而不是只给资源。
- 坏消息事件是否真的能转化为下一步动力。
- 伦理风险选项是否足够诱人但不鼓励无脑选择。
