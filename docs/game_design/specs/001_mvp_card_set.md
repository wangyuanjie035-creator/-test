## 目标体验

MVP 的 30 张基础卡和 5 张博士线扩展卡要先验证三件事：

- 玩家能明显感到自己在做“研究生行为”，而不是传统攻击防御换皮。
- 至少三种构筑雏形能出现：文献灵感流、实验数据流、卷王爆发流。
- 坏状态会制造压力，但玩家有方法处理，不会只是在挨打。

## 纸面测试基准

| 项 | 初始值 |
| --- | --- |
| 最大精力 | 50 |
| 每回合行动点 | 3 |
| 初始抽牌数 | 5 |
| 初始牌组 | 15 张 |
| 回合结束 | 未打出的手牌进入弃牌堆，防护清空 |
| 进度 | 对当前节点或 Boss 的推进值 |
| 压力 | 敌人造成的伤害，先扣防护，再扣精力 |
| 灵感、数据、草稿 | 节点内资源，战斗结束后清空或按结算规则转化 |
| 经费、声望 | 单局资源，跨节点保留 |

## 纸面测试关注点

- 初始牌组是否过慢，尤其是数据和草稿能否自然形成。
- `通宵赶稿` 和 `极限 ddl` 是否太强，是否需要更多后遗症。
- 论文牌是否有足够成就感。
- 负面牌是否烦但可处理。
- 每局是否能自然出现至少一种构筑倾向。
