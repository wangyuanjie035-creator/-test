# Phase 12：首日选择可理解性盲测 GDD

日期：2026-07-23  
状态：GDD v3，第二轮审查修订  
前置结论：Phase 10 证明实验台是稳定锚点，但不是结构性唯一解。

## 1. 阶段目标

验证玩家在没有口头指导、没有查看最优解的情况下，能否看见首日非实验候选的长期价值。

本阶段不验证“玩家是否选到数学最优”，而验证：

1. 玩家能否说出至少两个候选的不同未来收益。
2. 玩家是否知道自己的首选会改变哪一段生产链。
3. 玩家选择实验台时，是主动追求即时闭链，还是因为其他候选不可理解。

## 2. 核心假设

> 非实验首装路线已经客观存在，但当前界面可能没有把它们的长期价值表达得足够清楚。

若假设成立，应优化预览、文案和因果展示，而不是削弱实验台、增加奖励或扩大卡池。

## 3. 冻结范围

本阶段禁止修改：

- 卡牌产量、成本、技术债和触发条件。
- 初始资源、八天长度、胜负目标。
- 候选生成概率、卡池和累计课题奖励。
- 实验台与批量实验脚本的规则。

允许修改的内容仅限测试工具与证据记录；正式 UI 修改必须等待盲测结论。

## 4. 测试样本与 Seed 预注册

- Agent pilot：8 次独立首日决策，只用于发现流程、评分量表与 UI 证据问题，不产生正式 PASS。
- 外部盲测：至少 16 名首次接触游戏的玩家，每人只提供第 1 个 Seed 作为主要样本。
- 玩家可在同意后体验第 2 个 Seed，但只记为学习/复测数据，不与首曝百分比合并。
- Agent、开发者与外部玩家数据分别报告，禁止合并百分比。

Seed 从未使用区间按递增顺序机械筛选并预注册，不允许人工挑选。每个主测试 Seed 必须满足：

1. 首日同时出现实验候选与至少一个非实验候选。
2. Phase 10 同规则、束宽 512 的条件化搜索证明，被评估非实验候选与全局最优同样可胜，且 `regret <= 5`。
3. 文献、数据、分析三个非实验槽各至少获得 4 次有效近优曝光。
4. 预注册表固定 Seed、候选卡 ID、累计课题、分支可胜性、最佳论文、遗憾值和槽位；体验师与评分者在提交首选前不可看到这些搜索结果。

不满足近优条件的 co-offer 可作为负对照，但不计入“路线可解释率”失败。

## 5. 单次盲测流程

1. 展示第 1 天完整界面，不提供口头解释。
2. 主持人只说：“请像第一次玩一样，决定第一天怎么做；过程中可以把想到的内容说出来。”不得提及生产链、短期、长期或最优解。
3. 体验师自由观察并确认实际首选。记录玩家原话，不要求先完成三张排序。
4. 首选锁定后，先使用中性问题：
   - “你看到了哪些差别？”
   - “你预计做出这个选择后会发生什么？”
5. 中性回答锁定后，才询问：
   - “还有其他可以接受的选择吗？”允许回答“没有”或“不确定”。
   - 若答案键仍无法编码即时/长期理解，才使用固定补充追问；补充回答只进入“追问后理解”，不得回写无提示指标。
6. 最后才允许开始一天，并记录实际结果是否符合预期。

每次测试只观察首日理解，不要求完成整局，避免结局经验反向污染首选理由。

主要 PASS 指标只使用无提示记录；追问后记录用于诊断“完全看不懂”与“需要轻微提示才能理解”的差别。

## 6. 记录字段

| 字段 | 说明 |
|---|---|
| Seed | 测试 Seed |
| 候选集合 | 三张首日候选及槽位 |
| 第一选择 | 体验师最想安装的候选 |
| 可接受备选 | 首选锁定后询问；允许没有或不确定 |
| 玩家原话 | 未经研究员改写的选择理由 |
| 研究员摘要 | 与玩家原话分栏保存 |
| 即时预期 | 对今天资源与触发的预测 |
| 长期预期 | 对第 3–4 天瓶颈或收益的预测 |
| 自发比较/放弃理由 | 仅记录玩家主动提到的候选差异；未提及则留空，不追加诱导追问 |
| 实际结果 | 开始一天后的真实产出 |
| 预期偏差 | 正确、部分正确、错误 |
| 信心 | 1–5 |
| 决策时间 | 从界面稳定且玩家获得控制权，到首次确认首选点击 |
| 无提示理解 | 玩家自发说出的链段、时机与取舍 |
| 追问后理解 | 结构化追问后新增的正确理解 |
| 样本类型 | Agent pilot、外部首曝、学习复测或负对照 |

## 7. 评分量表

每个预注册候选必须在测试前建立答案键：

- 正确链段：该候选直接改变的输入、处理或输出环节。
- 正确时机：今天生效、条件满足后生效或第 3–4 天形成价值。
- 正确取舍：即时产出、延迟收益、资源瓶颈或技术债风险。
- 常见误解：把库存当日产出、把安装效果当立即兑现、忽略输入条件、误把课题奖励当卡牌能力。

每份外部首曝记录由两名未参与该次访谈的评分者独立编码。若“正确/错误”不一致，先标记评分分歧，不得由主持人单方面改判；分歧样本不进入正式百分比，直到完成盲态复核。

决策时间由测试工具自动记录界面稳定时间戳与首次确认点击时间戳。玩家口述、锁定后的追问和备选讨论均不计入时间；若自动记录缺失，允许用录屏复核，不允许人工估秒。

## 8. 可观察指标

### 主要指标

- **无提示路线可解释率**：至少正确指出一张已预注册近优非实验候选影响的生产链环节。目标 `>= 75%`。
- **无提示差异识别率**：在不要求备选或完整排序的情况下，玩家自发说出首选与任意另一候选的实质差异，而非只复述产量文字。所有有效外部首曝样本均进入分母；未自发比较记为“未识别”，不是缺失数据。目标 `>= 62.5%`。
- **实验主动选择率**：选择实验候选且理由明确指向即时闭链或爆发，而非“看起来最有用”。仅在实验选择样本 `>= 4` 时计算；分母不足时该诊断指标记为 `N/A`，不阻断总体裁决。
- **提示增益**：追问后理解率减去无提示理解率，只作诊断，不参与 PASS。

### 诊断指标

- 决策时间中位数目标 `<= 45 秒`。
- 信心中位数目标 `>= 3/5`。
- 已预注册近优非实验候选被评价为“不知道有什么用”的比例目标 `< 25%`。

## 9. 裁决顺序

严格按以下顺序裁决，避免状态重叠：

1. **INCONCLUSIVE**：外部首曝少于 16、任一非实验槽有效近优曝光少于 4、正式 PASS/FAIL 指标分母不足、评分分歧未解决或 Seed 预注册不完整。仅诊断指标分母不足不触发总体 `INCONCLUSIVE`。
2. **FAIL**：数据充分后，命中任一 FAIL 硬阈值。
3. **PASS**：未命中 FAIL，且全部 PASS 条件满足。
4. **CONDITIONAL**：数据充分但既未 FAIL，也未全部 PASS。

### PASS：路线存在且玩家看得见

同时满足：

- 无提示路线可解释率达标。
- 无提示差异识别率达标。
- 至少两个非实验槽各被主动列为首选或可接受备选一次。

处理：不改玩法、不改正式 UI，进入下一项中期决策审计。

### CONDITIONAL：路线可见，但表达有局部断点

出现下列任一情况：

- 玩家理解生产链，但误判某张候选的生效时机。
- 某一个非实验槽持续被误解，其他槽正常。
- 玩家能复述效果，却无法把效果映射到顶部生产链。

处理：只制作一个最小信息表达原型，例如候选悬停时高亮受影响链段、补充“今天/后续”标签或展示首个断点；不得增加奖励。

### FAIL：客观近优路线对玩家不可见

满足任一：

- 无提示路线可解释率 `< 50%`。
- 超过一半样本只因“实验台看起来唯一能立即工作”而选择实验候选。
- 三个非实验槽中有两个在至少 4 次有效近优曝光后仍从未进入首选或可接受备选。

处理：停止新增内容，先完成候选预览与因果表达修正，再用新 Seed 重测。

## 10. 四问检查

1. **新增判断**：玩家需要比较“今天立即闭链”与“为第 3–4 天建立瓶颈优势”。
2. **循环杠杆**：候选牌改变生产链的上游产能、处理中段或分析转化。
3. **成功放大**：实际开始一天后，界面应能指出玩家预期中的链段是否被点亮。
4. **失败归因**：玩家应能说出是候选价值没表达清楚，还是自己主动承担了延迟收益。

## 11. 不做事项

- 不根据 1–2 次体验立即调数值。
- 不把 Agent 偏好当成真实玩家统计结论。
- 不新增“推荐选择”或最优解箭头。
- 不通过额外论文奖励诱导非实验首装。
- 不扩大卡池、增加商店、地图或局外成长。
- 不把 Agent pilot 的 8 次结果包装成真人 PASS。
- 不在玩家锁定无提示答案前展示“今天/后续”、最优分支或 regret 信息。
- 不要求玩家为了完成记录表而强行给三张候选排序。

## 12. 交付物

- 8 份 Agent pilot 记录与至少 16 份外部首曝记录，分开汇总。
- Seed 预注册表与每张候选的答案键。
- 每个测试 ID 保存选择前截图、首选确认后的状态快照、Day 1 结算截图或事件日志；测试 ID 必须同时关联 Seed、候选集与记录行。
- 汇总表与 PASS / CONDITIONAL / FAIL / INCONCLUSIVE 裁决。
- 若未通过，仅允许提交一个信息表达原型 GDD；经确认后才实现。
