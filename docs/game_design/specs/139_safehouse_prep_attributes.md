# 139 住屋准备行动与智性/情性成长

## 目标

把住屋从“出门前菜单”推进成真正的策略准备空间。

当前 MVP 做三件事：

1. 住屋每天有有限准备行动点。
2. 每个行动都有明确目的，而不是单纯给奖励。
3. 行动会同时影响永久成长、即时资源和下一次校园地图倾向。

## 成长结构

第一版不使用“智商/情商”这种固定标签，而是拆成两组可成长能力。

### 智性成长

| 属性 | 目的 |
| --- | --- |
| `学术理解` | 读懂论文、理解理论、发现研究问题 |
| `方法论` | 把失败、混乱和负结果转化为可复用经验 |
| `实验工程` | 处理实验、设备、数据和工程实现 |
| `写作建模` | 把想法组织成草稿、论文结构和答辩材料 |

### 情性成长

| 属性 | 目的 |
| --- | --- |
| `表达控场` | 汇报、组会、答辩、说服导师或委员会 |
| `关系经营` | 导师、同门、行政、合作方互动 |
| `情绪韧性` | 抗压、恢复、坏事件后的稳定性 |
| `场面判断` | 判断何时争取、缓和、准备材料或撤退 |

## 准备行动

每天默认 `2` 个准备行动点。

| 行动 | 目的 | 成长 | 即时资源 | 带出效果 |
| --- | --- | --- | --- | --- |
| `休息调整` | 压住压力波动，避免下一次探索被坏状态拖垮 | 情绪韧性 +1 | 灵感 +1 | `缓冲心态`：偏灵感、休息、自我照护 |
| `文献阅读` | 建立研究问题感，让图书馆和论文线索更有价值 | 学术理解 +1 | 论文碎片 +1 | `文献线索`：偏阅读、图书馆、论文碎片、写作 |
| `预实验` | 提前排雷，让实验楼和设备相关收益更稳定 | 实验工程 +1 | 数据 +1 | `设备手感`：偏实验楼、设备、数据 |
| `模拟汇报` | 练习表达结构，为组会、导师和委员会场合做准备 | 表达控场 +1 | 声望 +1 | `汇报底稿`：偏导师、会议、委员会 |
| `复盘日志` | 把失败和混乱整理成方法，下次少走弯路 | 方法论 +1 | 经验教训 +1 | `复盘框架`：偏方法、复盘、返修 |
| `整理卡组` | 明确这次构筑方向，减少无效卡和摇摆路线 | 写作建模 +1 | 草稿 +1 | `构筑焦点`：偏草稿、写作、方法 |
| `材料归档` | 把数据、草稿和方法笔记整理成能快速调用的资料 | 场面判断 +1 | 方法笔记 +1 | `资料索引`：偏补给、方法笔记、数据、草稿 |
| `联系同门` | 提前约人交流，把孤立探索变成协作机会 | 关系经营 +1 | 经验教训 +1 | `同门窗口`：偏同门、合作、社交 |

## 地图生成影响

住屋准备不会替代阶段主线和主题选择，而是在候选池评分中增加一层轻量倾向：

```text
阶段必需标签 > 阶段焦点标签 > 主题三选一 > 住屋准备倾向 > 点位类型基础分
```

当前准备标签每命中一个候选点标签，额外加 `18` 分。

例子：

```text
文献阅读 + 模拟汇报
准备标签：阅读 / 图书馆 / 论文碎片 / 写作 / 会议 / 导师 / 委员会
```

这样玩家出门前做的准备，会实际改变下一次校园地图更容易出现什么内容。

## 手测重点

1. 住屋界面应显示智性/情性属性。
2. 每天应有 `2/2` 准备行动点。
3. 点击一个准备行动后，行动点减少，属性和资源增加。
4. 当天已做过的行动应禁用。
5. 行动点用完后，其他准备行动应禁用。
6. 出门后左上状态应显示 `准备2`。
7. 候选池审查应显示 `prep=...` 和 `prep_hits=...`。
8. 点击下一天后，准备行动点恢复，带出效果清空，但属性成长保留。
