# Phase 5：设置持久化

## 范围

本段只实现影响启动体验的两项设置，不扩展为完整选项菜单：

- 主音量：0%–100%，运行时即时预览。
- 窗口模式：窗口化 / 全屏，运行时即时预览。

动效强度、分轨混音、分辨率列表与按键重映射继续留在阶段 6 或更后，不占用当前玩法和美术的时间盒。

## 结构

- `LabSettingsStore`：使用 `ConfigFile` 保存 `user://lab_engine/settings.cfg`。
- `LabSettingsApplier`：把线性音量转换为 dB，并应用 Master Bus 和窗口模式。
- `LabSettingsOverlay`：轻量模态面板；修改时预览，关闭时一次写盘。
- `LabWorkbenchView`：只负责装配、故障降级和生命周期连接。

## 安全规则

- 当前格式版本为 v1；无版本配置按 v0 迁移。
- 写入采用同目录临时文件、验证后的上一代备份和重命名提交。
- 主配置损坏时从 `.bak` 恢复并重建主配置。
- 遇到未来版本主配置或备份时停止写入，防止旧客户端覆盖新字段。
- 测试场景关闭配置写入与运行时应用，并逐字节确认真实用户配置未改变。

## 验收

- 单元测试覆盖往返、归一化、v0 迁移、备份恢复和未来版本保护。
- 场景烟测覆盖设置按钮、音量、窗口模式、保存返回和重复实例化。
- 全量门禁日志固定写入项目 `.temp`，避免继续占用系统盘用户日志目录。
