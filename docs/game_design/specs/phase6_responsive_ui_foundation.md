# Phase 6：响应式 UI 与美术基础层

## 本段目标

在不调整玩法、数值、动效时长和音效强度的前提下，先保证工作台在首发桌面尺寸中稳定、统一、可读。

## 已实现

- 根级 `LabInterfaceTheme`：统一普通按钮、下拉框、焦点、按下、悬停、禁用态和基础文字颜色。
- 工位、候选卡、资源管线继续使用专属 StyleBox，不被通用 Theme 覆盖。
- 新增响应式场景门禁，完整实例化工作台并检查：
  - 1280×720（最低桌面目标）
  - 1920×1080（标准桌面目标）
  - 1280×800（16:10）
- 门禁检查根节点填满视口、关键控件不越界、候选区不与侧栏重叠。
- 真实运行时截图继续单独执行；headless Dummy Renderer 不承担像素截图职责。

## 范围边界

- 本段不加入复杂 Tween、粒子或音频混音调校。
- 暂不支持移动竖屏、超宽屏和手柄导航。
- 不通过修改玩法信息量来“解决”布局问题；先用容器、间距和视觉层级处理。

## 下一段

帮助、设置、结算三个模态层现已共享遮罩与面板语言：帮助层改为 Full Rect 并阻断底层鼠标输入；帮助与设置支持 `ui_cancel` 返回；打开时焦点进入模态层，设置和结算的主要控件形成循环焦点链。场景烟测覆盖全屏锚点、输入阻断、初始焦点、Esc 返回和单次提交。

长结算摘要现已置于纵向 `ScrollContainer`，重开按钮固定保留在面板底部；三档布局门禁会注入超长失败课题文案，验证面板、滚动区和两个按钮均不越界。帮助与设置会记住打开前的焦点并在关闭后延迟恢复；首次教程没有旧焦点时，工作台会聚焦第一张可用候选卡。

下一段进入阶段 6 收尾审查：整理当前视觉债清单，只处理会影响首次试玩理解或首发桌面分辨率的项目。
